# 调研：一手来源与引用落盘

调研结论写入 conclusion.md。

## 铁律

> 每个论断溯源到它的所有者来源（官方文档/源码/规范/一方 API），绝不转述二手转述。

## conclusion.md 结构

1. **结论**（先说答案，一段话）
2. **依据**：逐条"论断 → 来源 → 关键原文摘录"
3. **对比表**（如有选项对比）：维度 × 候选
4. **引用清单**：全部 URL
5. **不确定项**：哪些论断证据不足，如实标注

## 纪律

- 区分"来源说的"和"我推断的"，推断要标明
- 冲突来源并列呈现，不擅自裁决
- 无关紧要的细节不写，结论服务决策
