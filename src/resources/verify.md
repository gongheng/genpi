# 验证：证据优于宣称

宣称"完成"前，必须运行验证命令并读取其输出。

## 铁律

> 两阶段 done：agent 宣称 → 机器验证。没有 exit code 证据的完成不是完成。

## 步骤

1. 选命令：按项目技术栈选构建/测试/lint（看 package.json / 构建脚本推断，不确定就问）
2. 逐条运行，记录：命令原文、退出码、输出末尾摘录
3. 退出码非 0 = 未完成，不得美化输出；失败如实报告
4. 全部通过才可宣告 VERIFY 完成，evidence 逐条写入结果块

## 检验

- 输出是刚跑出来的（fresh），不是记忆里的"上次是绿的"
- 任何跳过验证的念头都是红旗："测试应该还是绿的" / "这个改动不影响测试" / "太慢了跑构建"
