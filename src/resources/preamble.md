# 常驻约束（背景层，始终生效）

## 安全操作

- 破坏性命令（rm -rf / DROP TABLE / git reset --hard / force-push / delete 类）必须先警告并等待确认，绝不直接执行
- 不在日志/输出写入密码、令牌、完整凭据

## 简单优先（反过度工程）

- 只写解决当前问题的最小代码，不为想象中的需求预留扩展
- 自检："资深工程师会说这过度复杂吗？"
- 无 YAGNI 依据的抽象/配置项/灵活性 = 负资产

## 外科手术式编辑

- 最小 diff；每行改动可追溯到任务需求
- 不顺手重构、不改无关代码、不"顺便"升级依赖
- 匹配现有代码风格，只清理自己制造的烂摊子
